# ⚠️ 本目录文档已作废（历史留档，勿据此开发）

## 作废原因

`docs/auth-v2/**` 描述的是 **「统一账号体系 v2」**：手机号跨小程序与 Web 打通、`user` 表单表存全部账号、
`phoneState` 三态驱动绑号门禁、`/users/auth/**` 六端点、`loginBySms` 短信验证码登录。

该方案已被**推翻**。当前实现是 **「双账号域拆分（wx / web）」**，两者方向相反：

| 维度 | 本目录（v2，作废） | 当前实现（双账号域） |
| --- | --- | --- |
| 账号表 | `user` 单表，跨端共用 | `wx_user`（小程序）与 `web_user`（后台）**两张表，零交集** |
| 手机号 | 跨端唯一主体，需「归属转移 / 恢复登录」 | web 端是账号标识；wx 端是可选便利项 |
| 绑号门禁 | `NEVER_BOUND` 硬拦截 reLaunch | **取消**硬拦截，改为「设置」页自愿绑定 |
| 登录方式 | 短信验证码登录 + 密码登录 | 后台**只有**手机号 + 密码；小程序微信一键登录 |
| 角色 | `CREATOR` / `USER` 双角色 + 升级页 | **单一角色**，RoleGuard / 升级页 / 管理员端点全部删除 |
| 端点 | `/users/auth/**`、`/users/creator/auth/**` 兼容并存 | `/users/auth/**`（wx）+ `/web/auth/**`（web）；旧端点已删 |

## 请改读

- **设计与上线**：`docs/双账号域拆分-上线与回归.md`（仓库 `docs/` 根目录）
- **DB 变更**：`sql/userService/双账号域拆分.sql`
- **网关路由快照**：`sql/gateway/gateway-routes.json`

## 保留理由

其中「D3 短信验证码即强凭据、被占用则自动转移」的论证仍然成立，但**适用范围已收窄为 wx 域**
（小程序绑定手机号）。阅读时请自行按此范围裁剪。
