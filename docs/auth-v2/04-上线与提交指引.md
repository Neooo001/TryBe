## 一、⚠️ 重要更正：网关白名单不在 Nacos

之前的口径是「去 Nacos 加 `hm.auth.excludePaths`」——**实测该判断有误**，现已核实并纠正：

| 项 | 事实 |
|---|---|
| 配置文件位置 | `TryBe-gateway/src/main/resources/application.yml`（**本地文件**，不是 Nacos） |
| 验证方式 | Nacos（192.168.100.128:8848）全量配置列表**无 gateway 相关 dataId**；网关 `bootstrap.yaml` 仅加载 `shared-log.yaml` + `shared-redis.yaml`，二者均不含 `hm.*` |
| 匹配逻辑 | `AuthGlobalFilter:145` 用 `antPathMatcher.match(pattern, path)`，**无通配符时为精确匹配** ⇒ 写具体路径安全 |
| git 状态 | 该文件**未被 git 追踪**（`.gitignore` 同时忽略 `**/application*.yml`）⇒ 改动只在本机，注意备份 |

**结论：无需改 Nacos。** 已在 `application.yml` 的 `excludePaths` 下加入 4 条：

```yaml
      # 统一账号体系 v2（2026-09-25）——以下 4 条为登录/发码入口，必须免鉴权
      # 注意：只列具体路径，禁用 /users/auth/** 通配（会连带放行 phone/bind）
      - /users/auth/captcha
      - /users/auth/sms/code
      - /users/auth/login/sms
      - /users/auth/login/password
```

并同步在文件末尾补了说明 3)：`/users/auth/phone/bind`、`/users/auth/phone` **刻意不放行**。

> MvcConfig 侧（`TryBe-common/.../config/MvcConfig.java:31-34`）已含同样 4 条，两层一致。
